# Instructions for coding agents

`namespy` is a pure-Python DNS stack: wire codec, iterative resolver, stub, and a loopback-only demo server,
with **no runtime dependencies**. It is the one implemented project in the portfolio that predates the
generator: nothing in it is generated by `sdk-forge/forge.py`, and nothing here should be regenerated.

## Commands

Run every command from this directory. Never run a formatter from `D:\code` (see `D:\code\AGENTS.md`).

```
python -m pip install -e ".[dev]"     # add ,crypto,doh for the DNSSEC and HTTP/2 rows
python -m pytest -q --cov             # --cov is load-bearing: fail_under is read only when measuring
python -O -m pytest -q -p no:cacheprovider   # the suite must also pass with asserts stripped
python -m ruff check .
python -m ruff format --check .
python -m mypy namespy
python -m build && python tools/check_dist.py dist/
```

Python 3.12+: `from __future__ import annotations`, `collections.abc`, `X | None`, `datetime.UTC`. `ruff format`
decides line breaks (line length 100). The default branch is `master`, not `main`.

## Invariants

- **No `assert` on anything that came off the wire.** It vanishes under `python -O`; raise
  `DnsPacketParseError` / `DnsNameParseError` with the datagram and offset. CONTRIBUTING.md rule 1.
- **Protocol behaviour cites its source by section**, in the form `RFC 9267 section 5`. CONTRIBUTING.md rule 2.
  The citation comes from the `rfclib` MCP tools, never from memory; HANDOFF.md rule 8 says to re-check any
  citation you touch against the document itself.
- **`docs/roadmap.md` is the completeness matrix.** A row reads ✅ only when a named test would fail if the
  behaviour regressed. Update the row in the same commit as the behaviour. Where cells name tests as
  `tests/<file>.py::<test>`; a test that does not exist yet is marked `(to be written)`.
- **Zero runtime dependencies.** Optional capability goes behind an extra (`crypto`, `doh`), named for the
  capability rather than the feature.
- **`--serve` binds loopback only.** It is a test fixture, not a service; see SECURITY.md.
- **RDATA serialises uncompressed**, because the sqlite cache re-parses stored records standalone.

## Planning

The matrix uses emoji statuses (✅ 🟡 ⬜ ▫️) and lives at `docs/roadmap.md` rather than `ROADMAP.md`. The
portfolio tooling reads it through an alias and a path override (D19 in
`sdk-forge/docs/improvement-plan.md`); do not convert the format. `docs/HANDOFF.md` is the running session
handoff and carries the start-here check: `git status --short` must be clean before work begins.

## Hygiene

- `.continue/`, `.cursor/`, `.vscode/` and the research corpus (`/*.txt`, `/*.pdf`, `docs/research.md`) are
  ignored on purpose. Never `git add -f` them, and never commit editor or agent configuration: this
  repository is public.
- Scratch output goes outside the repository.
- Commit messages carry no AI-attribution trailer.
